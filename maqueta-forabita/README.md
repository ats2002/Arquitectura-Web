# Maqueta estática de Forabita

Proyecto académico independiente construido con HTML, CSS y JavaScript puro.

No contiene backend, base de datos, credenciales, configuraciones privadas ni código del proyecto principal. Los formularios y acciones son demostrativos.

## Abrir localmente

Abre `index.html` directamente en el navegador o utiliza la extensión **Live Server** de Visual Studio Code.

## Publicar en GitHub Pages

1. Crea un repositorio nuevo en GitHub.
2. Sube solamente el contenido de esta carpeta.
3. En el repositorio, abre **Settings > Pages**.
4. Selecciona **Deploy from a branch**, la rama `main` y la carpeta `/root`.
5. Guarda los cambios.

## Archivos principales

- `index.html`: página principal.
- `buscar.html`: catálogo con filtros demostrativos.
- `detalle.html`: detalle de una vivienda.
- `seguridad.html`: recomendaciones de seguridad.
- `publicar.html`: formulario para arrendadores.
- `acceso.html`: inicio de sesión y registro.
- `styles.css`: identidad visual y responsive.
- `app.js`: navegación móvil, filtros, formularios y mensajes.
- `assets/`: logo e imágenes propias de la maqueta.

Las fotografías de viviendas se cargan desde Unsplash y requieren conexión a internet.
