# Agente de Estrategias Comerciales de Marketing Digital

Repositorio listo para GitHub con una version consultable del agente, su prompt maestro y una consola web estatica.

## Contenido

- `index.html`: aplicacion web estatica lista para publicar desde la raiz del repositorio.
- `dist/index.html`: copia compatible con hostings estaticos que publican desde carpeta de salida.
- `AGENT.md`: instrucciones completas del agente.
- `agent.config.json`: configuracion estructurada del agente.

## Uso rapido

Abre `index.html` en el navegador. Completa el brief del negocio y presiona `Listo` para generar una estrategia comercial con diagnostico, acciones, calendario, KPI, riesgos y siguiente mejor accion. Tambien puedes copiar el prompt maestro para seguir iterando en ChatGPT, Codex u otro modelo compatible.

## Publicar en GitHub Pages

1. Sube este repositorio a GitHub.
2. Ve a `Settings > Pages`.
3. En `Build and deployment`, selecciona `Deploy from a branch`.
4. Elige la rama principal y la carpeta `/root`.
5. Guarda los cambios.

## Base conceptual

El agente sigue una estructura basada en: tarea, arquetipo, contexto, tono, ejemplos, restricciones, formato, herramientas, flujo de trabajo, verificacion, memoria, escalamiento y criterios de parada.
